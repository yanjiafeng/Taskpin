评论附件（文件类型扩展）· 界面设计（任务 #116）

评论附件从「仅图片」扩展到 Word / Excel / PDF / Markdown 等文件。评论特点：图片是看一眼就够的内联内容，文件是要点开/下载的外部内容——所以图片维持内联缩略图不动，文件一律渲染成「可下载的条目」，不假装能预览。两个方向：A 纸条文件卡（纵向列表，信息全）、B 极简胶囊行（横向排列，省纵向空间）。

变体 A · 纸条文件卡（推荐）

每个文件一张小纸条：左侧扩展名「印章」按类型着色（PDF 红 / Word 蓝 / Excel 绿 / Markdown 灰），文件名超长省略，大小用等宽字体；整卡是 <a> 可键盘聚焦，点击下载。与图片缩略图共存时图片在上、文件在下。评论流 + 移动端全宽都不挤。

变体 B · 极简胶囊行
