项目多选筛选 · 交互设计

任务 #70。设计语言沿用产品既有方向：软木板顶栏 + 纸质浮层，不做新风格发明——多选控件是顶栏原生下拉的「原地升级」，按钮形态不变、浮层用与评论/卡片同源的纸张质感。交互要点：点按钮开合面板、checkbox 连续多选不收起、「全部项目」与具体项目互斥（点全部 = 清空选择）、点面板外或 Esc 收起、选中态持久化（刷新保留）。

状态 1 · 默认「全部项目」（未选任何项目）

按钮显示「全部项目」，看板不过滤。空选择 = 全部，与旧单选的 all 语义一致。

状态 2 · 选中 1 个 / N 个项目（收起态摘要）

单选时显示项目名；多选时收敛为「N 个项目」，避免顶栏被超长文本挤爆（移动端 max-width 104px 省略）。

📌 Taskpin

状态 3 · 面板展开（可交互，点 checkbox 试试）

「全部项目」是互斥项：勾选它即清空其余；勾选任一项目则「全部」自动取消。行尾灰字是该项目的任务数（可选增强，正式版先不做）。勾选手不收起面板，可连续多选；点面板外 / Esc 收起。

窄屏下按钮收缩为 ≤104px 省略号；面板从按钮下缘展开、纵向滚动，全部操作是 tap，无 hover 依赖。
